GitHub Pages 快速部署指南

只需 3 分鐘，免費將此作品集發布至個人專屬網域

1

建立 GitHub 儲存庫

登入 GitHub，新建一個 Public 儲存庫，命名為：
your-username.github.io

2

上傳 index.html 檔案

將本網頁程式碼另存為 index.html，並 Git Commit/Push 推送至儲存庫的主分頁 (main / master)。

3

開啟 Pages 服務

前往儲存庫的 Settings > Pages，Build and deployment 的 Source 選擇 Deploy from a branch (main) 即可完成部署！
